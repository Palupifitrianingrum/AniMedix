# AniMedix </br>

Website/Aplikasi untuk deteksi penyakit ternak menggunakan kecerdasan buatan (computer vision based). Peternak dapat mengunggah/scan foto ternaknya untuk mendeteksi penyakit, lalu mendapatkan rekomendasi tindakan penanganan yang ditampilkan di laman setelah penyakit terdeteksi. Peternak juga dapat terhubung ke dokter hewan untuk konsultasi lebih lanjut, mengetahui lokasi klinik terdekat, serta dapat terhubung ke komunitas peternak untuk berbagi info dan pengalaman. </br>
